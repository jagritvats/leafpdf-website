Edit PDFs on Linux with Leaf

Updated 19 November 2026 · Leaf 0.2.2

Leaf is a native PDF editor for Linux on x86_64. It follows your KDE or GNOME theme, light or dark, and works offline: edit existing text, redact, fill and sign forms, add digital signatures, recognize scanned text and organize pages.

Steps

  1. Check the requirements

    A 64-bit x86 system with glibc 2.34 or newer (Ubuntu 22.04, Debian 12, Fedora 35 and later all have it) and libOpenGL.so.0, which is the libopengl0 package on Debian and Ubuntu.

  2. Download

    Get the AppImage or the tarball from the download section. The AppImage is one file you run; the tarball is the app folder with its desktop entry, icons and a Dolphin service menu.

  3. Run the AppImage

    Make it executable, then run it:

    $ chmod +x Leaf-*-x86_64.AppImage
$ ./Leaf-*-x86_64.AppImage

    If your system has no FUSE, add --appimage-extract-and-run.

  4. Or unpack the tarball

    $ tar xzf leaf-*-linux-x86_64.tar.gz
$ cd leaf-*-linux-x86_64
$ ./leaf/leaf

    To add Leaf to your app menu, see Set up the tarball below.

  5. Open a PDF and start editing

    Drag a PDF onto the window or use File › Open… (Ctrl O). The list below links a guide for each task.

What you can do

  • Edit existing text: press I and click a line. Edit PDF text
  • Redact: press X, or Document › Search & redact…. Redact a PDF
  • Fill and sign forms: the Forms menu and Insert › Signature…. Fill and sign a form
  • Digital signatures: Document › Sign digitally…, and F12 to check them. Sign with a certificate
  • OCR: Document › Recognize text (OCR)…. Make a scan searchable
  • Pages: Ctrl Shift O for the organizer, leaf --merge a.pdf b.pdf to combine files. Merge and organize

Set up the tarball

The tarball's desktop entry and Dolphin service menu start Leaf as leaf, so put a small launcher on your PATH first. From inside the unpacked folder:

# a launcher in ~/.local/bin (on the PATH of most distributions)
$ mkdir -p ~/.local/bin ~/.local/share/applications
$ printf '#!/bin/sh\nexec "%s/leaf/leaf" "$@"\n' "$PWD" > ~/.local/bin/leaf
$ chmod +x ~/.local/bin/leaf

# the app menu entry and its icons
$ cp io.github.jagritvats.Leaf.desktop ~/.local/share/applications/
$ cp -r icons ~/.local/share/

# KDE: Combine with Leaf in Dolphin's right-click menu
$ mkdir -p ~/.local/share/kio/servicemenus
$ cp leaf-combine.desktop ~/.local/share/kio/servicemenus/
$ chmod +x ~/.local/share/kio/servicemenus/leaf-combine.desktop

Keep the unpacked folder where it is: the launcher points to it. To make Leaf your default PDF app, open Edit › Settings… (Ctrl ,), go to System and choose Make Leaf the default PDF app…. It needs the desktop entry installed and xdg-mime (xdg-utils).

If Leaf doesn't start

Run it from a terminal to see the error. A missing library is the usual cause. On Debian and Ubuntu, these packages cover what Leaf needs:

$ sudo apt install libopengl0 libegl1 libxkbcommon0 libxkbcommon-x11-0 \
    libfontconfig1 libdbus-1-3 libxcb-cursor0

Leaf isn't in distribution repositories, the AUR or Flathub yet. Updates are published on the releases page.
